# Информационная веб-система мониторинга антропогенной нагрузки на особо охраняемые природные территории (ООПТ)

Система представляет собой распределённый программно-аппаратный комплекс, в котором полевые датчики на базе микроконтроллеров Arduino собирают данные о состоянии окружающей среды, передают их на веб-сервер, реализованный на языке Java, а специалисты-экологи работают с системой через мобильное приложение на платформе iOS.
