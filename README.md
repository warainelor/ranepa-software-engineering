# Информационная веб-система мониторинга антропогенной нагрузки на ООПТ

Система принимает показания датчиков, установленных на особо охраняемых
природных территориях, сравнивает их с нормативами и сразу сообщает
инспектору о превышении.

## Пользователи

Инспектор ООПТ, эколог-аналитик, оператор мониторинга, администратор,
руководитель.

## Возможности

- Автоматический приём показаний датчиков Arduino (температура, влажность,
  CO2, шум, задымлённость).
- Сравнение показаний с пороговыми значениями и создание тревоги.
- Push-уведомления инспекторам на iPhone.
- Карта зон со статусами, карточка датчика с графиком за 24 часа.
- Фиксация выезда и закрытие тревоги с итогом.
- Отчёты за период с выгрузкой в PDF.
- Управление устройствами, пользователями и порогами (администратор).
